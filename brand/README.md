# Sokage brand kit

**One mark. Two offset planes — orange over white on ink.** It reads as layers, a fold, a document
turning. Chosen because it survives 16 pixels, which is the only size a favicon is ever seen at.

**Colours:** orange `#EE6A1A` · ink `#1B1715` · cream `#FBF7F3` · white `#FFFFFF`

---

## Which file do I use

| Where | Use |
|---|---|
| **Website favicon** | `sokage-mark.svg`, with `favicon.ico` as the fallback |
| **GitHub / social avatar** | `sokage-avatar-512.png` |
| **App icon, phone home screen** | `sokage-mark-180.png` |
| **On a photo or a coloured block** | `sokage-glyph-512.png` — transparent, no container |
| **On a dark background** | `sokage-glyph-on-dark-512.png` |
| **Letterhead, email signature, deck header** | `sokage-lockup-1200.png` |
| **Print, embroidery, one colour** | `sokage-glyph-mono-ink-1024.png` |
| **Anything that needs to scale** | any `.svg` — they are infinitely sharp |

## Everything in here

**Vector (use these wherever you can)**

- `sokage-mark.svg` — primary, ink ground
- `sokage-mark-light.svg` — for white and cream backgrounds
- `sokage-glyph.svg` — mark only, no container, transparent
- `sokage-glyph-on-dark.svg` — same, for dark grounds
- `sokage-glyph-mono-ink.svg` / `sokage-glyph-mono-white.svg` — single colour
- `sokage-lockup.svg` — mark plus **Sokage AI** wordmark

**Raster**

- `sokage-mark-{16,32,48,64,128,180,256,512,1024}.png`
- `sokage-glyph-{256,512,1024}.png` — transparent
- `sokage-glyph-on-dark-{256,512,1024}.png` — transparent
- `sokage-lockup-{600,1200,2400}.png`
- `sokage-avatar-512.png` — for GitHub, Skool, social
- `favicon.ico` — multi-size, for browsers that still want one

## Rules

**Do**

- Leave clear space around it — at least the height of one plane on every side.
- Use the ink version on light backgrounds and the light version on dark ones. Contrast is the whole
  point of the mark.
- Scale the SVG. It has no minimum size that breaks it.

**Do not**

- Recolour it. The orange is the brand; a blue one is a different company.
- Stretch it. The 30-degree fold angle is the mark. Distort it and it becomes a generic parallelogram.
- Add a shadow, gradient, glow, or outline.
- Rebuild it in a slide deck. Use the file.
- Put the orange version on another strong colour. It needs ink, white or cream behind it.

**Minimum size: 16px.** It was tested there before it was chosen.
