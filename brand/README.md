# Brand

**One mark, two colourways.** Same shape everywhere — favicon, GitHub, the site — so it is
recognisable at 16 pixels.

| File | Use it |
|---|---|
| **[sokage-mark.svg](sokage-mark.svg)** | Primary. White S on Sokage orange. **This is the favicon** |
| **[sokage-mark-dark.svg](sokage-mark-dark.svg)** | Orange S on ink. For light backgrounds and print |
| **[sokage-mark-512.png](sokage-mark-512.png)** | 512px raster, for anywhere SVG is not accepted |

**Colours:** orange `#EE6A1A`, ink `#1B1715`, white `#FFFFFF`.

**Do not** recolour the mark, stretch it, add a drop shadow, or place the orange version on another
strong colour. It is a solid block on purpose — a colour a browser tab can be recognised by.

Live on the site at [sokage.com](https://sokage.com).
